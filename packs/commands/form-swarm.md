# Form an Agora swarm

In at most two sentences, tell the user which swarm you will form and which method, role, capability,
actor-kind, and delegation checks you will confirm. Continue without reconfirming unambiguous
assignments; pause for a material assignment choice or new authority.

Read the selected Method Pack and its role files. Discover project and user actors, including actors
whose kind is `swarm`, with the narrowest queries that resolve required roles. Assign only declared
capabilities and allowed actor kinds. Create the swarm and persist assignments with Agora. For a
linked child, verify `represented-swarm`, readiness, and delegation depth. Never invent capabilities
or credentials. Report assignments, confirmed checks, blockers, and next action.
