# Agora

Local, Git-native governance for the agentic SDLC. Humans, AI agents, services, and swarms
deliver software under one accountable record — multi-LLM, multi-language, multi-methodology,
multi-org. Markdown is the ledger.

```
pip install agora-framework
agora init
```

## Why Agora

- **Multi-LLM** — actors authenticate and are permission-scoped the same way regardless of model
  or vendor.
- **Multi-methodology** — spec-driven, Scrum, Kanban, or a custom Method Pack; Agora enforces
  whichever one is installed.
- **Multi-language** — governs the process around the code, never the code itself.
- **Multi-agent, multi-swarm** — delegation is budget-bounded and append-only.
- **Multi-provider** — 14 reviewed adapters (GitHub, GitLab, Jira, Terraform, AWS, GCP,
  Confluence) behind provider-neutral Tool Packs.
- **Multi-org trust** — Ed25519-signed packs and registries, optional transparency log.

Status: alpha (0.4.0), ready for controlled pilots. See the [roadmap](roadmap.md) for open gaps.
