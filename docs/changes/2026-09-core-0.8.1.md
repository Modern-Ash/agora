# Agora Core 0.8.1

Agora Core 0.8.1 is a patch release focused on autonomous-session efficiency and operational
compatibility. It scopes session context to active work, bounds durable transcripts, adds
provider-neutral execution profiles, records authentic Codex token telemetry, permits concurrent
read locks, short-circuits unchanged compact inspections, and adds grouped validation output.

The bundled command skills now prefer compact snapshots, targeted reads, quiet commands, bounded
tool output, and profiles proportional to the work. Project schema remains `0.4.0`; existing
workspaces require no durable schema migration, but should synchronize their materialized command
adapters after installing Core 0.8.1.
