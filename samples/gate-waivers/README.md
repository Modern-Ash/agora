# Gate Waivers sample

This sample advances Scrum work to verification, shows the completion gate rejecting missing
obligations, records one granular Product Owner exception with risk evidence, and completes the same
work without weakening its transition graph or role policy.

Run it from the repository root:

```bash
uv run python samples/gate-waivers/run.py
```

The temporary project retains the generated `WAIVER.md`, work events, and completed projection.
See [Granular Gate Waivers](../../docs/guides/gate-waivers.md) for CLI and signed-action usage.
